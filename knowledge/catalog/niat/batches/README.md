# NIAT Batch Catalog Inputs

Store batch-specific NIAT curriculum-source inputs here.

Recommended layout:

```text
knowledge/catalog/niat/batches/
  b3/
    bos_curriculum_references.csv
    grid_template_references.csv
  b4/
    ...
```

These CSVs should contain canonical references such as:

- university names
- branch or program names
- publicly accessible BOS curriculum sheet links
- curriculum grid template links
- other source-of-truth references used to build implementation curricula
