# Target Learner Persona Analysis

## Primary Persona: Career Switcher
- Background: 1-3 years in software development or adjacent field
- Prior knowledge: Basic Python, some SQL, web development fundamentals
- Knowledge gaps: Statistics, ML theory, production ML systems
- Misconceptions: "ML is just calling sklearn.fit()", "More data always helps"
- Motivation: Career advancement, salary increase, intellectual curiosity
- Learning preferences: Visual + hands-on, project-based, practical over theoretical
- Time availability: 10-15 hours/week
- Pain points: Overwhelmed by math prerequisites, unclear learning path

## Secondary Persona: Fresh Graduate
- Background: CS/Math/Statistics degree, 0-1 years experience
- Prior knowledge: Strong math, algorithms, some Python
- Knowledge gaps: Production systems, software engineering practices, industry context
- Misconceptions: "Research papers = production code", "Academic datasets represent real data"
- Motivation: First ML engineering role, build portfolio
- Learning preferences: Theory + practice balanced, likes formal structure
