# Learning Platform — product cuts taxonomy (HOD paste, 2026-08-12)

Three cuts of the LP product surface (verbatim structure):

**BY Outcomes:** Curriculum Design & Development (learning environments & evaluation
mechanisms) · Curriculum Delivery · Assessments (proctoring, grading, third-party
integrations — Woolf, university customisations).

**BY Code/Features:** Content types (MCQs, multi-answer, code-analysis, image, FIBs,
tutorials [MCQs+coding exercises], guiding questions, coding questions, projects) ·
Learning environments (in-app playgrounds: HTML/CSS/JS, Python, JS, Java, C++; cloud
IDEs & plugins: Spring Boot, React, Node; GenAI) · Evaluation mechanisms & judges ·
Learning support (AI tutor, error reporting, feedbacks, debug) · Video tooling
(hotspots, live classroom quiz) · Student engagement (bookmarks, public submissions,
publishing) · Analytics & tooling · Assessments & proctoring.

**BY User Flows (canonical grouping for the LP scorecard):**
1. Platform Discovery Flow — post-onboarding course/activity discovery, personalized dashboard.
2. Core Learning Outcomes Flow — shared base: video player + hotspots, progress, AI tutor,
   all content types, live quiz, summary cheatsheets, error reporting, feedback collection.
3. Curriculum/Stack-Specific Learning Outcomes Flow — programming (playgrounds, debug,
   guiding questions, bookmarks, public submissions) · CS Core · app/software dev (web
   playgrounds, publishing, cloud IDEs) · aptitude (timed, adaptive difficulty) ·
   English (pronunciation, grammar, vocabulary) · GenAI · DevOps/DA/Testing.
4. Assessment & Evaluation Flow — cross-course tests, projects, evaluations, progress.
