# NSPI / SPI — NIAT Skill Performance Index (decoded from NSPI_Student_Edition.pptx, 2026-08-11)

Per-course skill score 0–10, per skill cycle.

**Course score (Skill Track Score, /100)** = Classroom Quizzes ×10% + Module Quizzes ×15%
+ Skill Assessments (every 15–30 days) ×25% + Final Skill Assessment ×50%.
Score→level→points: 90–100 A+ =10 · 80–89.99 A =9 · 70–79.99 B =8 · 60–69.99 C =7 ·
50–59.99 D =6 · <50 F =0 · Absent =0. Min 50% needed in EACH component.

**Cycle SPI** = Σ(course points × course weight) ÷ Σ weights (example cycle: BackEnd 4,
DAA 4, AI for Finance 4, Prob&Stats 3, Stat Computing Lab 1, Logical Reasoning 3,
Applied Communicative English 3).

**Eligibility gates** (else no SPI): attendance ≥80% (recovery mode below), 100%
classroom-quiz participation, 100% module-quiz completion, 100% skill-assessment
participation, mandatory FSA, no malpractice.

**Skill Debt** (F/Ab): auto-enrolled recovery window → recovery classes → pending work →
FSA re-attempt. Any active debt = ineligible for MINT/BRAVE/GRIT, placements, internships,
co-curricular support; clear within next cycle or program review. Malpractice: course
reset to fail, no retake that cycle.

**Org target (Jul'27):** 30% of students ≥8.0 · 40% at 7.0–8.0 · 30% at 6.0–7.0.

**Department linkage:** the score is 100% assessment-composed — classroom quiz items
(A/B/C live slides), module quiz items, skill assessments are all department-authored
instruments; mastery quality drives the 75% (SA+FSA) weight. Attendance/participation
gates are program-ops-owned. Note tension: dept KPI baseline marks Summative/Formative
Achievement "pending deprecation," yet SPI is 75%-weighted on those assessments —
deprecation should keep an SPI-component view (or gold-tier extends to cover SA/FSA).
