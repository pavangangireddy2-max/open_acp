Problem - 1


       To calculate the time complexity of a single ‘for’ loop, the loop iterates N times
       from i = 1 to i = N and then the loop performs two actions: updating i(to N+1) and
       checking the condition. Since the condition fails at i = N+1, the loop terminates.


                                          # Steps = 3 * N + 2


         The number of steps is given by 3N + 2, indicating that the time taken by the algorithm
                   varies linearly with the input size, with a multiplication factor of 3.

Key Takeaways

     ●   Algorithm efﬁciency is about how resources like time
         and space grow as input increases.

     ●   Time Complexity – Measures how the number of
         steps in an algorithm grows with input size (e.g., O(1),
         O(N), O(N²)).

     ●   Asymptotic Notation – Big O (worst case), Big Ω (best
         case), and Big Θ (average/tight bound) help describe
         algorithm efﬁciency.
