What is a Variable?




                 A variable is essentially a container used to store data

                 It can be accessed and modiﬁed during program
                 execution
Variables

What is a Variable?



                      Python and JavaScript are dynamically typed languages

                      Type of variable is decided at runtime
Variables

What is a Variable?



            Example in JavaScript                       Example in Python


                                Javascript                                  Python

let sport = "Cricket";                       sport = "Cricket"
Variables

Deﬁning a Variable in JavaScript



               Variables are created using keywords like let, const, or var

               Their type is determined by the assigned value (e.g.,
               number, string)

               Statements may end with semicolons, though they are
               optional
Variables

Deﬁning a Variable in Python



                In Python, variables can be created directly without
                any keywords

                A variable is created automatically when you assign a
                value to it
Variables

Example


                                                      Python

                  age = 10
                  sport ="Cricket"


             The moment you assign age a value (age = 10), the
            variable age is created and the value 10 is stored in it
Variables

Variable Naming Rules & Conventions


                Must start with a letter or an underscore (_)

                Cannot start with a number

                Case-Sensitive: Variables like age and Age are
                considered different

                No KeyWords: You can't use Python keywords like
                print, if, or True as variable names
Variables

Variable Naming Rules & Conventions

                                       Key Difference




                  JavaScript                                  Python
            Variable names can start                A variable cannot start
              with a dollar sign ($)                    with a dollar sign ($)
Variables

Variable Naming Rules & Conventions

              Best Practices for Naming Variables




                  Snake case is preferred (e.g., user_age)




                  Camel case is used (e.g., userAge)

Primitive Data Types




               Primitive types are basic data types like numbers,
               strings, and booleans

               They hold single values and form the building
               blocks of data in programming
Primitive Data Types

Integer



                           Integer (int): Whole numbers


                       Represents positive , negative numbers and Zero
                                  without a fractional part

                                           numbers.

type( ) Function in Python



             type() is a built-in function in Python that allows you
             to determine the type of a variable

             It is used to check what data type a variable holds,

             Helpful for debugging or for ensuring that the
             variable is of the expected type
Data Types

type( ) Function in Python

                                   Python

 age = 42                                                                           Output
 print(type(age))                                       <class 'int'>
                                                        <class 'str'>
 name = "Alice"
 print(type(name))


             Here, the type() function is used to print the type of age and name,
                           which are an int and a str respectively

Constants in JavaScript



            JavaScript provides a keyword called const to declare constants




                  Used when the value should remain ﬁxed
                           throughout the program
Constants

Constants in Python



            Python does NOT have a const keyword

            Python does not provide any built-in feature to create true
            constants

            Developers follow a naming convention to indicate constants
Constants
