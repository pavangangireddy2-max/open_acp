Introduction


            A function is a predeﬁned set of instructions that takes input,
            performs a speciﬁc task, and returns an output, enabling an
                   efﬁcient way to reuse code for repetitive tasks.


                                           Syntax

                      return_type function_name(data_type parameter)
                      {
                          // Function code or instructions
                          return result;
                      }

Passing Parameters to Functions



                                  Pass by Value

            Pass by value is a parameter passing method where a copy of the
            actual argument is passed to the function. Changes made inside
                    the function do not affect the original variable.
Passing Parameters to Functions by Value

Example


                            C++
           void passByvalue(int a)
           {
           a = a + 2;                                Output
           cout<<"Function: a = "<< a << endl;
           }                                     Function: a = 4
           int main(){
                                                 Main: a = 2
               int a = 2;
               passByvalue(a);
               cout<<”Main: a = “<< a << endl;
               return 0;
           }
Functions

Passing Parameters to Functions



                                Pass by Reference

            Pass by reference is a parameter-passing method where a function
            receives a reference to the actual argument, allowing modiﬁcations
                     inside the function to affect the original variable.
Passing Parameters to Functions by Reference

Example


                            C++
           void passByReference(int &a)
           {
           a = a + 2;                                Output
           cout<<"Function: a = "<< a << endl;
           }                                     Function: a = 4
           int main(){
                                                 Main: a = 4
               int a = 2;
               passByReference(a);
               cout<<"Main: a = "<< a << endl;
               return 0;
           }

Passing Array to Function

             array's name, which decays into a pointer to its ﬁrst element,
                        effectively making it pass by reference.


                                        Syntax

          Feature                      C++ Syntax                           Python Syntax
     Function Declaration   int add(int, int);                        No separate declaration available.

     Function Deﬁnition     int add(int a, int b) { return a + b; }   def add(a, b): return a + b


     Function Calling       sum = add(5, 10);                         sum = add(5, 10)

     Pass by Value          Default                                   Default

                                                                      Use mutable objects (lists, dicts) or
     Pass by Reference      Use & (e.g., void modify(int &x))
                                                                      global keyword
