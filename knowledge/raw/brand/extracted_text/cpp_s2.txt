Explicit Type Conversion



      In Explicit Type Conversion, programmers
      explicitly change the data type of a value
      to the desired data type. This type of conversion
      is also called Type Casting.
Explicit Type Conversion

Implicit Type Conversion




      The C++ compiler automatically converts
                                                                   C++
      one primitive data type to another when a
      value is assigned to a variable of a different type.   int x = 10;
                                                             long long y = x;
      This process is called Implicit Type Conversion.
C++

Implicit Type Conversion

      Data Type   Bits Acquired

      bool        8 bits (1 byte)

      char        8 bits (1 byte)
                                      This conversion happens without the need for
      short       16 bits (2 bytes)
                                        explicit casting by the programmer and is
      int         32 bits (4 bytes)    done in cases where the conversion is safe

      long long   64 bits (8 bytes)   and doesn't result in loss of data or precision.

      ﬂoat        32 bits (4 bytes)

      double      64 bits (8 bytes)
