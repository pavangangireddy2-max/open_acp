Loop Control Statements



      Control statements alter the sequential
      execution of a program.


      In both Python and C++, loop control
      statements break and continue work similarly.
Break Statement

Example
                                                       Output
                        C++
        #include <iostream>                                1
        using namespace std;
                                                          2
        int main() {
            int num_seq[] = {1, 2, 3, 4, 5};              3
            for (int i = 0; i < 5; i++) {
                if (num_seq[i] == 4) {
                    break;                     The break statement is used to
                }                              stop a loop and move on to the
                cout << num_seq[i] << endl;       next part of the program.
            }
            return 0;
        }
