Permutations in C++ STL



       A permutation is a rearrangement of elements in a given order.


       C++ provides the next_permutation() and prev_permutation()
       functions to generate lexicographic permutations.
Generating the Next Permutation

About


       What does next_permutation() do?


       The next_permutation() function is part of the
       <algorithm> header in C++.

       It rearranges elements in the given range to generate the
       next lexicographical permutation of the sequence.
Generating the Next Permutation

About

                            Input                                                          Output



  ➢    A range deﬁned by two iterators: (ﬁrst, last)                   ●   Returns true if the previous permutation exists
                                                                           and modiﬁes the range in-place.
   ●   ﬁrst: Iterator pointing to the beginning of the                 ●   Returns false if the given range is the smallest
       range.                                                              permutation (sorted in ascending order), in
   ●   last: Iterator pointing one past the last element of                which case the sequence is rearranged to the
       the range.                                                          largest permutation (sorted in descending order).




                                                     Important note
                The function modiﬁes the original sequence directly.
                If no next permutation exists, the sequence is rearranged in descending order.
Generating the Next Permutation

Example

                               C++
     #include <iostream>
                                                                     Output
     #include <algorithm>
     using namespace std;
     int main() {
         string str = "abc";

         }

About

       What does Sorting Required?


       The sorting step ensures that the permutations are
       generated in lexicographical order when using
       next_permutation().

       If the input string is not in sorted order, the function will
       continue from its current arrangement, missing some
       permutations at the star.

                           bool customSort(int a, int b) {
                               if (abs(a) == abs(b))
                                  return a < b;
                               return abs(a) < abs(b);
                           }


                           void customSorting(vector<int>& arr) {

                           }
Max Element

Problem Statement



        Given a vector nums of size n containing integers,
        check if the difference between the maximum
        element and the ﬁrst element exists in the vector. If
        found, print "Present".
Max Element

Problem Statement


                                Input                            Output


                          n=5
                                                                 Present
                          nums = [3, 1, 7, 4, 2]




              The ﬁrst element is 3, the maximum is 7, and since 7 - 3 = 4 exists in the
                                      vector, the output is "Present".
Max Element

Solution

                                             C++
              #include<bits/stdc++.h>
              using namespace std;


              void checkPresence(vector<int>& nums) {
                  int first = nums[0];
                  int maxElement = *max_element(nums.begin(), nums.end());
                  int difference = maxElement - first;


                  if (find(nums.begin(), nums.end(), difference) != nums.end()) {
                      cout << "Present" << endl;
                  } else {
                      cout << "Not Present" << endl;
                  }
              }

Problem Statement



         Given a string s, ﬁnd the next k lexicographically greater
         permutations of s. If there are fewer than k permutations
         available, return only the ones that exist. Return the result as
         a vector of strings in sorted order.
Finding All Permutations for an Array

Problem Statement


                              Input                     Output


                               s = "abc"
                                                     ["acb", "bac"]
                               k=2




                The next permutation after "abc" is "acb", followed by "bac".
Finding All Permutations for an Array

Solution

                                                     C++
                        #include<bits/stdc++.h>
                        using namespace std;


                        vector<string> findNextPermutations(string s, int k) {
                            vector<string> result;


                            while (k-- && next_permutation(s.begin(), s.end())) {
                                result.push_back(s);
                            }


                            return result;
                        }
