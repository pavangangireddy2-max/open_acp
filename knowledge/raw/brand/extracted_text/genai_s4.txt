Format

Format

Example

          Act as an experienced travel consultant ...
          I'm a 22-year-old college student ...
          Recommend 2 speciﬁc destinations ...

          Format:
            1.    For each destination, create a section that includes:
                    ●    A brief overview (3-5 sentences)
                    ●    An Estimated cost breakdown (accommodation, food, activities, transport)
                    ●    Safety considerations for solo travelers
            2.    Then provide a day-by-day itinerary in a table format with the following columns for:
                    ●    Day #
                    ●    Morning activity
                    ●    Afternoon activity
                    ●    Evening activity
                    ●    Accommodation
            3.    End with a pros/cons list for each destination

Prompting Techniques

Zero-shot



      Zero-shot prompting is a technique
      that instructs an LLM to perform a task
      without providing any examples
Zero-shot

Example

            Summarize the following paragraph about Generative AI:


            Generative AI refers to artiﬁcial intelligence systems capable of
            creating new content, such as text, images, music, and videos that
            resemble human-created work. Unlike traditional AI, which focuses on
            analysis and prediction, generative AI can produce original outputs
            based on patterns learned from training data. Popular examples
            include GPT models for text, DALL-E for images, and MusicLM for
            music creation. These systems have sparked discussions about
            creativity, copyright, and the future of human-machine collaboration in
            creative ﬁelds."
Zero-shot

Example

            Classify this review as positive or negative:


            The restaurant was incredible, best meal I've had all year.




            Response: Positive

Tricks and Tips

Separating Data from Instructions




 Instead of writing a new prompt each time,
 you can create a reusable prompt template and
 that can be reused with different data each time
Tricks and Tips

Separating Data from Instructions




 This is especially useful when you need
 the LLM to perform the same task repeatedly
 but with different input data
Tricks and Tips

Example 1: Simple Template




                  I will tell you the name of an animal. Please respond with

                  the sound that animal makes. {{ANIMAL}}
Tricks and Tips

Why Separate Data from Instructions




         Reusability                 Consistency                      Clarity

   Create once, use multiple     Same task structure        Keeps instructions separate
   times with different data   ensures consistent results      from variable content
