Set Operations

Problem Statement


          Implement these functionality on a set -

         add x : Inserts element x into set s.

         print : Prints all elements of set s, space-separated.

         remove x : Removes element x from set s.

         check x : Prints 1 if x is present in s, otherwise prints -1.

         length : Prints the size of set s.
Set Operations

Problem Statement


                       Input           Output


                 Queries = add 1
                           add 2
                           print      1 2
                           remove 2
                           check 3    -1
                           check 1     1
                           length      1
Set Operations

Explanation


     →   add 1 → Inserts 1 into the set → Set: {1}
     →   add 2 → Inserts 2 into the set → Set: {1, 2}
     →   print → Prints the set contents: 1 2
     →   remove 2 → Removes 2 from the set → Set: {1}
     →   check 3 → Checks if 3 is present in the set → Output: -1 (since 3 is not in the set)
     →   check 1 → Checks if 1 is present in the set → Output: 1 (since 1 is in the set)
     →   length → Prints the size of the set → Output: 1 (since set contain only 1 element)

C++ STL - Set

Key Takeaways


    →   Set
        Stores unique elements in sorted order, supports
        operations like insert(), erase(), ﬁnd(), size(), and
        swap().

    →   Multiset
        Similar to set, but allows duplicate elements
        while maintaining sorted order. Provides count()
        for duplicate occurrences.
C++ STL - Set

Key Takeaways


    →   Unordered Set
        Stores unique elements in an arbitrary order,
        offering generally faster insertions and lookups
        compared to set.

    →   Operations
        All sets support insertion, deletion, iteration,
        checking existence, clearing, swapping, and size
        retrieval.
