Syntax

CSS - Cascading Style Sheets

    A CSS File will be created.
    It is a list of RuleSets.
    Each Ruleset looks like:


                                selector   {
                                               property1: value1;
             Ruleset
                                               property2: value2;
                                           }
Syntax

Selector - Name

     First, decide a suitable name
     for the selector and use it

     Ex: h-center
         horizontal-center
         horizontal
         center
         horizontal_center
         HorizontalCenter, etc.
Syntax

CSS Ruleset - To Center Elements

             SELECTOR



         .h-center {
             text-align: center;
         }
