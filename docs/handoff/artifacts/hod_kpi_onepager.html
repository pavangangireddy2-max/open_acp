6. Where these KPIs meet the NIAT targets

Each target, the KPIs that carry it, and the mechanism — read a branch as: this number moves → this happens → the target moves. The table below adds what the department does about each.
SPI bands · 30% at ≥8.0 · 40% at 7.0–8.0 · 30% at 6.0–7.0 — read as a flow: deliver → quiz → align → assess
  • 1. PLE Program Delivery Gap → 0% — classes and assessments happen as planned: lecture schedule adherence · classroom-quiz attendance, attempts & performance · practice schedule adherence & completion % · module-quiz schedule adherence & integrity. Only when all of these meet target does step 2 land
  • 2. LD Module-Quiz Score Bands — target: 30% of students at ≥8.0 · 40% at 7.0–8.0 · 30% at 5.0–7.0 · none below 5.0 — same shape as the SPI bands
  • 3. LD Content–Assessment Alignment — score delta between the department-authored quizzes and the skill assessments; target: delta = 0 — students score the same on both, so teaching matches testing. Only when steps 1–3 meet target does step 4 land
  • 4. LD Summative & Formative Achievement — the SPI band target carried into the skill assessments (75% of SPI, authored by the Assessments department): same 30/40/30 distribution on assessment scores, per batch
Academics CSAT · 4.5 / 5
  • ACP Content Issue Resolution Efficiency ≥80% · Content Issue Recurrence = 0 — fixed in 48 h (≥80% within the 2-day TAT), and never twice → trust in content
  • DP Learning Environment Satisfaction ≥4.5/5 — the platform rating, measured monthly; driven by Availability & Saturation Detection (issues caught before students feel them) · Tail-Latency User Impact (coding feels instant) · Platform Issue Resolution Efficiency (fixed fast) · Platform Issue Recurrence (never twice)
  • PLE Product Issue Resolution CROSS-DEPT — every student-reported issue tracked to done end-to-end, whichever department owns the fix; first-quarter baseline sets the TAT target · recurrence = 0 from day one
University Relations CSAT · 4.5 · 4.0 · 4.0
  • PLE BOS Credit Acceptance — targets 85% B3 · 90% B4 — credits proposed per BOS cycle accepted into university curricula; set from past acceptance data (B3 Sem-3: 81.4% across 17 universities · B4 Sem-1: 90.1% across 36, of which 3 — Bharath, PK Das, Visakha — are still finalising curriculum)
  • PLE Program Delivery Gap → 0% — the delivered program matches the approved plan
  • PLE Curriculum & Framework Compliance — BOS / AICTE / UGC kept → zero partnership risk
GRIT Novice Badges · 5,000
  • LD Industry Update Adherence (Learning–GRIT delta → 0) — course content reaches GRIT (industry) level → contest pass rate 16→30% → badges
  • PLE GRIT upskilling experience — learning and practice provided to move students toward badges (GRIT Practice, post-contest recommendations)
