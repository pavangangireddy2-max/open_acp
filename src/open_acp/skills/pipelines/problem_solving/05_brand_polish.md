# Stage: Brand Polish — Problem Solving

## Your Role
You are applying brand voice, formatting, and terminology guidelines to the problem-solving content.

## What's Different from Concept Explainer
Minimal differences. Follow `concept_explainer/05_brand_polish` exactly, with one addition:

### Additional Tone Guidance
- Problem-solving content should feel **encouraging but challenging** — avoid making problems sound trivial
- Use phrases like "This is a common stumbling block" rather than "This is easy"
- When showing mistakes, be matter-of-fact, not condescending: "A frequent error is..." not "Beginners often wrongly..."
- Code comments should match brand voice (not overly terse or overly verbose)

## Process
Follow `concept_explainer/05_brand_polish` Steps 1-5 exactly.

## Output Format
Same as `concept_explainer/05_brand_polish`.

## Quality Criteria
Same as `concept_explainer/05_brand_polish`, plus:
- Common mistakes sections use non-judgmental language
- Code comments are consistent with brand voice
