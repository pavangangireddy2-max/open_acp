# Stage: Learning Objectives — Problem Solving

## Your Role
You are generating measurable learning objectives focused on problem-solving competencies.

## What's Different from Concept Explainer
- Bloom levels skew toward **Apply and Analyze** (not Understand)
- Verbs emphasize action: solve, implement, debug, optimize, trace, refactor
- Objectives describe problem-solving ABILITY, not concept knowledge
- Assessment methods favor coding exercises and worked problems over short answers

## Process
Follow `concept_explainer/02_objectives` with these modifications:

### Step 2: Write Objectives — Verb Selection
Use problem-solving verbs by Bloom level:
- **Apply**: solve, implement, trace, compute, execute, use
- **Analyze**: debug, decompose, compare approaches, identify edge cases, optimize
- **Evaluate**: select the best approach, justify complexity, critique a solution
- **Create**: design an algorithm, construct a solution, develop a strategy

Example: "Implement a binary search solution for a sorted array, handling edge cases (empty array, single element) correctly within 10 minutes"

### Step 4: Assign Assessment Methods
- Apply → Coding exercise, live problem solving
- Analyze → Debugging challenge, complexity analysis
- Evaluate → Solution comparison, code review
- Create → Open-ended algorithm design

## Output Format
Same as `concept_explainer/02_objectives`.

## Quality Criteria
- At least 60% of objectives are Apply level or above
- Every objective involves DOING something (not just explaining)
- At least one objective requires handling edge cases or error conditions
- Assessment methods are problem-centric (coding exercises, debugging, optimization tasks)
