# Stage: Learning Objectives — Learning Support

## Your Role
You are generating measurable learning objectives focused on correcting misconceptions and building accurate mental models.

## What's Different from Concept Explainer
- Bloom levels focus on **Understand and Apply** (correcting, not creating)
- Verbs emphasize correction: identify, correct, distinguish, differentiate, explain why X is wrong
- Objectives describe what learners should STOP thinking as well as what they should think
- Assessment tests whether the misconception has been resolved

## Process
Follow `concept_explainer/02_objectives` with these modifications:

### Step 2: Write Objectives — Verb Selection
Use correction-focused verbs:
- **Understand**: distinguish, differentiate, explain why, contrast, clarify
- **Apply**: correct, fix, identify errors in, rewrite, demonstrate the correct approach
- **Analyze**: diagnose, trace the error in, compare correct vs incorrect

Example: "Distinguish between pass-by-value and pass-by-reference by correctly predicting the output of 3 code snippets that exploit the difference"

### Step 4: Assign Assessment Methods
- Understand → Error identification quiz, true/false with explanation
- Apply → "Fix the bug" exercises, before/after code correction
- Analyze → "What's wrong with this explanation?" critiques

## Output Format
Same as `concept_explainer/02_objectives`.

## Quality Criteria
- Every objective maps to a specific misconception from the outline
- At least one objective uses "distinguish" or "differentiate" (comparing correct vs incorrect)
- Assessment methods test misconception resolution, not just concept knowledge
- Objectives are written so that someone WITH the misconception would fail them
