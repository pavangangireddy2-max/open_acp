# Stage: Learning Objectives — Platform Walkthrough

## Your Role
You are generating measurable learning objectives for platform/tool usage.

## What's Different from Concept Explainer
- Bloom levels focus on **Apply** (doing things in the platform)
- Verbs are action-oriented: navigate, configure, use, set up, troubleshoot, customize
- Objectives describe platform tasks, not conceptual understanding
- Assessment is task completion (can you do it?)

## Process
Follow `concept_explainer/02_objectives` with these modifications:

### Step 2: Write Objectives — Verb Selection
Use platform-action verbs:
- **Remember**: locate, identify, find, recognize (UI elements)
- **Apply**: navigate, configure, set up, use, install, connect, export
- **Analyze**: troubleshoot, diagnose, compare settings, identify issues
- **Evaluate**: select the right tool/feature, assess configurations

Example: "Configure a Python virtual environment in VS Code, including interpreter selection and terminal integration, within 5 minutes"

### Step 4: Assign Assessment Methods
- Remember → UI element identification quiz
- Apply → Follow-along task completion, screen recording
- Analyze → Troubleshooting scenario (fix a broken configuration)

## Output Format
Same as `concept_explainer/02_objectives`.

## Quality Criteria
- At least 70% of objectives are Apply level (doing, not knowing)
- Every objective specifies a concrete platform action
- At least one objective addresses troubleshooting
- Objectives are testable by observing platform state (not just asking questions)
