# Stage: Rubric Design — Final Course Quiz

## Your Role
You are creating a comprehensive rubric for a high-stakes final course quiz.

## What's Different from Skill Assessment
- Highest stakes — rubric must be unambiguous and fair
- Multi-part and synthesis questions need detailed component rubrics
- Must support consistent grading across multiple graders and sections
- Total point value is higher (reflecting quiz importance)

## Process
Follow `skill_assessment/03_rubric_design` with these modifications:

### Point Allocation
- MCQ: 2 points each
- Short answer: 3-4 points each
- Code-based: 4-5 points (detailed partial credit)
- Scenario/case study: 6-8 points (per-part rubric)
- Big idea / synthesis: 8-10 points (component rubric with quality levels)

### Synthesis Question Rubrics
For "big idea" questions, use a quality-level rubric:
- **Excellent** (90-100%): Integrates concepts from 3+ modules, provides specific examples, justifies with reasoning
- **Good** (70-89%): Integrates 2 modules, provides examples, some justification
- **Adequate** (50-69%): Mentions relevant concepts but doesn't integrate well
- **Insufficient** (<50%): Shows only surface-level recall

### Grading Guide
- Produce a grading guide document with:
  - Quick scoring checklist per question
  - Example excellent, good, and inadequate responses
  - Calibration notes: "q15 and q22 are the hardest — expect lower scores"

## Output Format
Same structure as `skill_assessment/03_rubric_design`, with higher point totals and quality-level rubrics.

## Quality Criteria
- Total points in 70-100 range
- Synthesis questions have quality-level rubrics (not just binary)
- Example responses at 3+ quality levels for open-ended questions
- Grading guide enables consistent scoring
- Passing threshold is defined (typically 50-55% for a comprehensive final)
