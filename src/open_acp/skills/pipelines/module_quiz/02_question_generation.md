# Stage: Question Generation — Module Quiz

## Your Role
You are writing 10-15 quiz questions that assess understanding across a full module (4 sessions).

## What's Different from Classroom Quiz
- More questions (10-15 vs 5-8)
- Higher Bloom levels (Understand/Apply focus vs Remember/Understand)
- Cross-session questions that combine concepts from different sessions
- More code-based questions (if programming topic)

## Process
Follow `classroom_quiz/02_question_generation` with these modifications:

### Format Mix
- 6-8 MCQ questions (follow mcq_practice rules)
- 2-3 Short answer (explain, compare, or predict)
- 1-2 Code tracing / output prediction
- 1-2 Cross-session integration questions (combine concepts from 2+ sessions)

### Cross-Session Questions
These questions test whether learners can connect ideas:
- "Given what you know about X (Session 5) and Y (Session 7), what would happen if...?"
- "Compare approach A (from Session 6) with approach B (from Session 8)"
- These should be at Apply or Analyze level

### Difficulty
- Moderate — an attentive student should score 60-70%
- Include 1-2 challenging questions that require genuine analysis
- Code questions can be 5-10 lines (longer than classroom quiz)

## Output Format
Same as `classroom_quiz/02_question_generation`.

## Quality Criteria
- 10-15 questions total
- At least 2 cross-session integration questions
- At least 3 format types used
- Code questions are syntactically correct
- Questions span all 4 sessions (no session skipped)
