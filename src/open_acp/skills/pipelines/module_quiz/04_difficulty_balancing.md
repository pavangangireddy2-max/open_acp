# Stage: Difficulty Balancing — Module Quiz

## Your Role
You are verifying that quiz difficulty matches its summative purpose for a single module.

## What's Different from Classroom Quiz
- Higher overall difficulty (summative, not formative)
- Expected average score: 60-75% (not 70-85%)
- Must include at least 1-2 genuinely challenging questions
- Cross-session questions add complexity

## Process
Follow `classroom_quiz/04_difficulty_balancing` with these modifications:

### Difficulty Targets
- Easy: 25-30% of questions (baseline recall/understanding)
- Medium: 45-50% of questions (solid understanding required)
- Hard: 20-25% of questions (analysis, cross-session integration)

### Time Feasibility
- MCQ: 1-2 minutes each
- Short answer: 3-4 minutes each
- Code tracing: 3-5 minutes each
- Cross-session: 4-5 minutes each
- Total should fit within 25-35 minutes

### Balance Verification
- No single session's questions are all easy or all hard
- Cross-session questions are not the ONLY hard questions
- The quiz is passable even if learners struggle with the hardest questions

## Output Format
Same as `classroom_quiz/04_difficulty_balancing`.

## Quality Criteria
- Expected average score is 60-75%
- Difficulty spread matches targets
- Time fits within 25-35 minutes
- No session is unfairly over-represented in hard questions
- Quiz is passable (60%) without getting the hardest questions right
