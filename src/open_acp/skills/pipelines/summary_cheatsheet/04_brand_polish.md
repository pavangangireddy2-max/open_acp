# Stage: Brand Polish — Summary Cheatsheet

## Your Role
You are applying brand guidelines to the cheatsheet while preserving its concise format.

## What's Different from Other Pipelines
Follow `concept_explainer/05_brand_polish` with these constraints:

### Critical Constraints
- Do NOT add prose for the sake of brand voice — brevity is paramount
- Brand polish here means: consistent terminology, consistent formatting, correct tone in the 1-2 sentence descriptions
- Table formatting must be standardized (column widths, alignment)
- Code snippet style must match brand code standards (naming conventions, comment style)

### What to Polish
- Term consistency (same concept = same word everywhere)
- Formatting consistency (all tables use the same column structure pattern)
- Tone in descriptions (concise but brand-appropriate)
- Code style (variable naming, comment format)

### What NOT to Polish
- Do not expand concise entries into longer prose
- Do not add transitions between sections (it's a reference, not a narrative)
- Do not add opening/closing paragraphs to sections

## Process
Follow `concept_explainer/05_brand_polish` Steps 1-5, respecting the constraints above.

## Output Format
Same as `concept_explainer/05_brand_polish`.

## Quality Criteria
- Brevity is preserved (word count does not increase by more than 10%)
- Formatting is consistent across all tables and lists
- Terminology is consistent throughout
- No added prose that undermines the quick-reference format
