# Stage: Learning Objectives — Induction

## Your Role
You are generating measurable objectives for an onboarding/induction session.

## What's Different from Concept Explainer
- Bloom levels focus on **Remember and Understand** (orientation, not mastery)
- Verbs are orientation-focused: identify, locate, describe, set up, access
- Objectives are about KNOWING WHERE THINGS ARE, not deep understanding
- Assessment is checklist-based (did you set up X? can you find Y?)

## Process
Follow `concept_explainer/02_objectives` with these modifications:

### Step 2: Write Objectives — Verb Selection
Use orientation verbs:
- **Remember**: identify, locate, name, list, find
- **Understand**: describe, explain, summarize, outline
- **Apply**: set up, configure, access, navigate, register

Example: "Set up a complete development environment including Python 3.10+, VS Code with required extensions, and Git, verified by running the provided health check script"

### Step 4: Assign Assessment Methods
- Remember → Resource location quiz ("Where do you find X?")
- Understand → Program structure summary
- Apply → Setup completion checklist, health check script

## Output Format
Same as `concept_explainer/02_objectives`.

## Quality Criteria
- Objectives are achievable in a single session (no multi-day objectives)
- At least one objective is a verifiable tool setup
- Objectives cover logistics (where to find things) and setup (tools working)
- No objectives require prior domain knowledge
