# Stage: Rubric Design — Skill Assessment

## Your Role
You are creating a scoring rubric for a placement-linked skill assessment.

## What's Different from Module Quiz
- Higher total points (more questions, more complex questions)
- Integration questions need multi-component rubrics
- Scenario-based questions need rubrics that reward reasoning, not just answers
- Grading consistency is critical at this stakes level

## Process
Follow `module_quiz/03_rubric_design` with these modifications:

### Point Allocation
- MCQ: 2 points each
- Short answer: 3 points each
- Code tracing / debugging: 3-4 points (with partial credit)
- Integration/scenario questions: 4-5 points (multi-component rubric)

### Multi-Component Rubrics
For integration/scenario questions, break scoring into components:
- Component 1: Identifies the relevant earlier concept or dependency (1 point)
- Component 2: Applies the current concept correctly (1 point)
- Component 3: Integrates both into a coherent solution (2 points)
- This makes partial credit fair and grading consistent

## Output Format
Same structure as `module_quiz/03_rubric_design`, with higher point totals.

## Quality Criteria
- Total points in 40-60 range
- Integration questions have multi-component rubrics
- Partial credit is proportional to demonstrated understanding
- Passing threshold is defined (typically 55-60%)
- Example responses at 3 quality levels for complex questions
