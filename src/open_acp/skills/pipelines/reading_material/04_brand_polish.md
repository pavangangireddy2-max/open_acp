# Stage: Brand Polish — Reading Material

## Your Role
You are applying brand voice, formatting, and terminology guidelines to the reading material.

## What's Different from Session Pipelines
Follow `concept_explainer/05_brand_polish` with these adjustments for written content:

### Additional Guidance
- Reading material has NO presenter — voice must work entirely on the page
- Ensure a conversational but professional tone throughout (like a great technical blog)
- Transitions between sections must be smooth (no "as I mentioned" — use "as described in the previous section")
- Code block formatting: ensure consistent language tags, consistent comment style
- Callout types should be used for: tips, warnings, deep-dives, "check your understanding"

## Process
Follow `concept_explainer/05_brand_polish` Steps 1-5 exactly.

## Output Format
Same as `concept_explainer/05_brand_polish`.

## Quality Criteria
Same as `concept_explainer/05_brand_polish`, plus:
- No spoken-language artifacts ("let me show you", "as I said")
- Callout formatting is consistent throughout
- Code comment style matches brand voice
